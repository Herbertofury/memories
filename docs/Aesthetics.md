## Attribution and asset boundaries

[CARI's attribution guidance](https://cari.institute/attribution-guidelines) separates foundational artists, works, researchers and name coiners. Preserve those roles rather than assigning a style to whichever moodboard is easiest to find. CARI explicitly positions its artifacts as research references, not free assets. Web Design Museum also credits screenshots to their respective owners. For all sites, a public image or a save button is not a redistribution/model-training/game-use license. Link to original artists; record rights separately before copying any media.

## How this collection grows

- Mark styles **explicit favorite**, **recovered project style**, or **discovery suggestion** independently.
- Capture the user's actual wording and source privately; publish only the requested aesthetic preference, not private conversation transcripts.
- Keep aliases and broader movements distinct; a custom theme label is not automatically an established historical movement.
- For each example retain creator, original URL, date precision, source type and rights status. Unknown dates stay unknown.
- Do not infer personal taste from a generic UI requirement, installed package, source-code default or an assistant's suggestion.
- Keep the list editable. New preferences can replace old ones without making the old project catalog authoritative.

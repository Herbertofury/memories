## Useful discovery sites, organized by task

These are editorial recommendations based on the public features observed below, not a benchmark proving one universally best. Search terms connect to the recovered styles without claiming those styles are already confirmed favorites.

| Resource | Best use here | Observed access and limits | Connection |
|---|---|---|---|
| [CARI aesthetic index](https://cari.institute/aesthetics) | Start with named consumer-design styles and historical context | Public index offers keyword, relevant-decade and date filters; individual names/dates can remain research questions | Search Frutiger Aero, Y2K, Memphis, Vaporwave and related names |
| [Web Design Museum](https://www.webdesignmuseum.org/) | Compare actual historical websites, software, apps and Flash-era visual language | Public galleries, period groupings and Y2K exhibition; screenshots remain their owners' copyright | Ground Neo-Y2K and nostalgic interfaces in dated examples |
| [Are.na](https://www.are.na/) | Follow connections between references and organize source-linked moodboards | Public homepage describes searchable channels and networking; account/subscription features were not tested | Cross-style collections for liminal, retro-futurist and surreal references |
| [Designspiration](https://www.designspiration.com/) | Visual idea discovery and saving references | Public landing page observed; JavaScript required for full experience, sign-in features not tested | Color/material/typography discovery across styles |
| [Savee](https://savee.com/) | Designer-curated boards and visual reference retrieval | Public product page describes word/color/image/tag search; some capabilities require paid plans; not tested in an account | Compare material, composition and palette references rather than copying a preset |

## Attribution and asset boundaries

[CARI's attribution guidance](https://cari.institute/attribution-guidelines) separates foundational artists, works, researchers and name coiners. Preserve those roles rather than assigning a style to whichever moodboard is easiest to find. CARI explicitly positions its artifacts as research references, not free assets. Web Design Museum also credits screenshots to their respective owners. For all sites, a public image or a save button is not a redistribution/model-training/game-use license. Link to original artists; record rights separately before copying any media.

## How this collection grows

- Mark styles **explicit favorite**, **recovered project style**, or **discovery suggestion** independently.
- Capture the user's actual wording and source privately; publish only the requested aesthetic preference, not private conversation transcripts.
- Keep aliases and broader movements distinct; a custom theme label is not automatically an established historical movement.
- For each example retain creator, original URL, date precision, source type and rights status. Unknown dates stay unknown.
- Do not infer personal taste from a generic UI requirement, installed package, source-code default or an assistant's suggestion.
- Keep the list editable. New preferences can replace old ones without making the old project catalog authoritative.

## Coverage gaps

The recovered 17-package inventory is verified against public migrated source. Earlier user-message searches did not return matching preference messages in this pass. GameSync Next was inspected at repository overview level, not exhaustively audited. The full personal favorite list therefore remains unconfirmed. Discovery pages were read, but there was no account sign-in, image copying, subscription, full-site crawl or hands-on ranking experiment.

# Discover characters, creators and worlds

Reviewed 2026-11-15. Memories serves two separate purposes: preserving favorites and finding new ones. **A discovery suggestion is not automatically a favorite, a canonical source, or permission to use an asset in JetSetCraft.**

## Where to start

These are task-based editorial picks, not a measured universal ranking.

- **OC browsing:** [ocbin](https://www.ocbin.com/characters/) exposes a character directory with tags and pagination. The available indexed page is older, so counts are not represented as current totals. [OCFancy](https://ocfancy.com/) describes linked character profiles, worlds and stories; its public/private sharing boundaries matter. [Art Fight](https://artfight.net/) is an art-gifting community with recent-character, rules and filtering routes, not a blanket asset library.
- **Interconnected worlds:** [World Anvil's public directory](https://www.worldanvil.com/community/browse) has genre filters and featured worlds. It supports discovery rather than only creation tools. Content maturity varies by world; the directory includes an adult category. No restricted category was opened in this review.
- **Creator-owned lore:** start with [FENNAH's Satellite City repository](https://sfennah.wixsite.com/satellitelore), [Skashi's lore post](https://skashi95.newgrounds.com/news/post/1530400), and [Twokinds' official cast directory](https://twokinds.keenspot.com/characters/). FENNAH's older lore scope is not a substitute for all The August Few book continuity. Skashi's post distinguishes timelines and work in progress; it is not proof every future lore post is indexed. Twokinds connects its cast information to the official comic and separately links fan galleries.
- **Species leads:** [WikiFur's fictional-species category](https://en.wikifur.com/wiki/Category:Fictional_species) helps find names and creator trails, but is a community encyclopedia, not a rights grant or primary canon source.
- **Visual styles and art references:** use the task-grouped resources in [Aesthetics](Aesthetics.md). Follow discoveries back to the artist rather than copying from aggregators.

## Important corrections and limits

- The attachment alleged Refsheet.net shut down on September 1, 2026. This review obtained only the [official JavaScript-required shell](https://refsheet.net/), not a shutdown announcement. The shutdown claim remains **unverified**; a loading shell proves neither closure nor normal service.
- Toyhouse returned 403; Vilous timed out. Unvale and CharacterHub yielded little or no readable text. These are access/review limits, not proof that the services are dead.
- Fan wikis can be useful indexes but must be visibly separated from creator-authored lore. Trace citations to primary sources before importing character facts.
- Creator galleries and world communities can contain mature material. Preserve source ratings and warnings, do not bypass age/authentication/paywall controls, and do not preview unknown-rating imagery automatically. No adult imagery, downloadable model, archive or paid post was fetched for this directory.
- All linked artwork, characters and texts retain their own rights. A public profile, art-gifting permission, closed-species registration or purchase does not automatically license redistribution or a game adaptation. Apply [character intake rules](Character-intake-rules.md) and [model reference checks](Model-references.md).
- No account was created, followed, joined or paid for. This pass checked public text only; it did not test logged-in searches, enumerate every character, or copy the attachment's third-party image embeds.

## From discovery to favorite

1. Save a candidate with the original creator URL and an explicit discovery status.
2. Separate creator identity, character owner, artwork artist, lore author and model maker.
3. Preserve official, creator-authored, fan, index and unverified labels for each source.
4. Only the owner's selection promotes a candidate to a personal favorite. A source site's featured list is not the owner's preference.
5. Link official social/support profiles only when self-linked or otherwise corroborated; keep inaccessible destinations labeled.
6. Track Memories publication separately from JetSetCraft design request, asset clearance, implementation and native testing.
